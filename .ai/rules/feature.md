# Feature

## Allow workspace members to manage Search Console
Any user with access to an active workspace project may connect, select, sync, reconnect, or disconnect its Google Search Console integration. Continue requiring an exact verified-host match, keep GSC data out of public dashboards, and delete tokens, imported metrics, and GSC-derived data on disconnect.
