# Mcp

## Keep setup assistance credential-safe
Setup guidance and MCP responses may report coarse readiness only. Never return or accept API keys, OAuth tokens, passwords, public share URLs/tokens, or other credentials. Sensitive areas (Google Search Console, workspace AI, members, profile, security, sharing, and MCP connections) remain guidance/status-only; use explicit approval for permitted operational writes.
