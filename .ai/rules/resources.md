# Resources

## Use the xelqun dark visual system
Keep the frontend on the xelqun theme tokens: dark background #0b0d0e, card #131517, primary #009965, border #23262b, sidebar #0d0f10, Outfit + Geist Mono, and a 1rem base radius. Shared controls should use the xelqun flat dark surfaces, rounded-md controls, rounded-xl cards, and restrained borders/shadows.
